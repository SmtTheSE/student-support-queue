# Font assets

Inter and Source Serif 4 are served locally as Latin variable WOFF2 fonts. Both are licensed under the SIL Open Font License 1.1; the license texts are included here.

- Inter: https://github.com/google/fonts/tree/main/ofl/inter
- Source Serif 4: https://github.com/google/fonts/tree/main/ofl/sourceserif4

The site's warm editorial treatment is inspired by Anthropic and Claude's public websites. These open fonts provide the sans-serif and serif pairing; they are not Anthropic's proprietary fonts.
